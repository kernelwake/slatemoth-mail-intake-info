SlateMoth Mail Intake

An owner-operated personal automation for the SlateMoth editorial workflow. This informational site has no sign-in form and does not receive credentials or article submissions.

What the application does

The private controller reads the owner's self-addressed Muse article delivery messages and validates three original JSON attachments. A separate owner-controlled pipeline performs mechanical checks, builds the site, checks pages, and requests a restricted SlateMoth release. The controller does not treat an email or a review report as proof of publication.

Google authorization uses gmail.readonly. This grants read access to the entire connected Gmail mailbox, even though the fixed intake code searches for specific SlateMoth delivery messages. It cannot send, modify, label, or delete email. Muse's separate sending connection is not authorized by this application.

This application is intended only for its owner's account, not a public Gmail service. The production publishing loop remains disabled until its authorization, resource, and release checks pass. This page does not claim Google verification or that unattended publishing is already enabled.
